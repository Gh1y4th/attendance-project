# Attendance project\n\nSchool attendance system with a Firebase/Express API, a Netlify dashboard, and a local Python face-recognition camera client.\n\n## Data flow\n\n1. `attendance_camera.py` recognizes a live, known face.\n2. It sends `{ name, confidence_score }` to `POST /api/attendance` on the Render backend.\n3. The dashboard reads attendance from `GET /api/attendance` after Firebase sign-in.\n4. Unknown faces are sent to `POST /api/pending-faces`.\n5. A dev or school admin approves a pending face in the dashboard. The camera polls `GET /api/pending-faces/sync`, learns the returned `full_name` / `image_base64`, and marks it synced.\n\n## Camera client setup\n\nSet the same service secret that is configured on the Render backend before starting the camera. Do not put the secret in source code or commit it to GitHub.\n\n### Windows PowerShell\n\n`$env:PYTHON_SERVICE_API_KEY = "your-rotated-secret"`\n\n### macOS/Linux\n\n`export PYTHON_SERVICE_API_KEY="your-rotated-secret"`\n\nThen run:\n\n`python attendance_camera.py`\n\nThe client expects the existing `known_faces/` and `anti_spoof_models/` folders beside the script.\n\n## Security\n\nRotate any service key that has previously appeared in a script, chat, log, or repository. Keep `FIREBASE_SERVICE_ACCOUNT_PATH` and `PYTHON_SERVICE_API_KEY` in Render environment variables only.\n
